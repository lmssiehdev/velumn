Velumn only indexes public Discord threads that server admins have selected for indexing. messages in regular chats, DMs, and private channels are never collected. We also don't display user avatars to provide an additional layer of privacy.

When you delete a message in Discord, it's automatically removed from the forum.

## What Gets Synced

We only sync the essentials needed to create a searchable forum experience:

- **Public threads only** - regular text channels, DMs, and private channels are never synced
- **Message content** - only from threads that are being synced
- **Your display name**

## You Have Full Control

You can manage your data at any time using the `/manage-account` command in any server with Velumn:

- **Anonymize**: Replace your display name with a randomly generated name across all past and future forum posts
- **Delete All**: Permanently remove all your synced messages from all forums and prevent future syncing
- **Restore**: (Coming soon) Re-enable message syncing after using Delete All

If you have any questions or concerns about your privacy, please reach out to me on discord.
